# Project CV
*Um site de portfólio simples para exibir detalhes pessoais e profissionais.*

## 🚀 Demonstração ao Vivo
[Project CV - Versão Online](https://project-cv-five.vercel.app/)

## 📌 Sobre o Projeto
Este é o meu primeiro projeto de desenvolvimento web, criado para praticar habilidades de front-end e construir uma página de portfólio pessoal.

## 🛠️ Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript
- Vercel (para implantação)
  
## 🎯 Funcionalidades
- Informações pessoais e exibição de projetos.
- Interface limpa e moderna.

## 📌 Melhorias Futuras
- Design responsivo para diferentes tamanhos de tela.
- Adicionar mais interatividade com JavaScript.
- Melhorar os recursos de acessibilidade.
- Otimizar o desempenho e animações.
